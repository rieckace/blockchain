Ex. No. 5: Decentralized Cryptocurrency Wallet

Aim

Design and implement a functional prototype of a Decentralized Cryptocurrency Wallet capable of generating cryptographic keypairs (public/private keys), deriving blockchain addresses, constructing signed transactions, verifying signatures, and managing local account balances.

Procedure

  1. Create a project folder named CryptoWalletLab and install necessary dependencies (ecdsa).
  2. Implement key generation routines using SECP256k1 Elliptic Curve Cryptography (ECDSA) to generate private and public key pairs.
  3. Derive a public blockchain address by performing SHA-256 hashing on the public key.
  4. Create a Wallet class to encapsulate key management, address derivation, and transaction signing logic.
  5. Implement transaction construction functionality where a transaction payload contains sender address, recipient address, transfer amount, and timestamp.
  6. Implement digital signing of transactions using the sender's private key and cryptographic verification using the public key.
  7. Demonstrate functionality in if __name__ == "__main__": by creating two wallets, funding an account, constructing and signing a transaction, verifying its signature, and logging output.

Code

import hashlib
import time
import json
from ecdsa import SigningKey, VerifyingKey, SECP256k1, BadSignatureError

def sha256_hex(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()

class Wallet:
    def __init__(self):
        # Generate private key and public key pair using SECP256k1
        self.private_key = SigningKey.generate(curve=SECP256k1)
        self.public_key = self.private_key.verifying_key
        self.address = self.derive_address()

    def derive_address(self) -> str:
        pub_bytes = self.public_key.to_string()
        return sha256_hex(pub_bytes)[:40] # 40-character hexadecimal address

    def sign_data(self, message: str) -> str:
        sig_bytes = self.private_key.sign(message.encode())
        return sig_bytes.hex()

    @staticmethod
    def verify_signature(public_key_hex: str, message: str, signature_hex: str) -> bool:
        try:
            vk = VerifyingKey.from_string(bytes.fromhex(public_key_hex), curve=SECP256k1)
            return vk.verify(bytes.fromhex(signature_hex), message.encode())
        except BadSignatureError:
            return False

class Transaction:
    def __init__(self, sender_wallet: Wallet, recipient_address: str, amount: float):
        self.sender_address = sender_wallet.address
        self.sender_pubkey_hex = sender_wallet.public_key.to_string().hex()
        self.recipient_address = recipient_address
        self.amount = amount
        self.timestamp = time.time()
        self.signature = ""

        # Sign transaction upon creation
        self.sign_transaction(sender_wallet)

    def to_json(self) -> str:
        return json.dumps({
            "sender": self.sender_address,
            "recipient": self.recipient_address,
            "amount": self.amount,
            "timestamp": self.timestamp
        }, sort_keys=True)

    def sign_transaction(self, sender_wallet: Wallet):
        tx_data = self.to_json()
        self.signature = sender_wallet.sign_data(tx_data)

    def is_valid(self) -> bool:
        if not self.signature:
            return False
        tx_data = self.to_json()
        return Wallet.verify_signature(self.sender_pubkey_hex, tx_data, self.signature)

if __name__ == "__main__":
    print("--- Initializing Decentralized Wallet System ---")
    alice_wallet = Wallet()
    bob_wallet = Wallet()

    print(f"Alice's Address: 0x{alice_wallet.address}")
    print(f"Bob's Address:   0x{bob_wallet.address}")

    print("\n--- Creating & Signing Transaction ---")
    tx = Transaction(alice_wallet, bob_wallet.address, 25.5)
    print(f"Transfer Amount: {tx.amount} ETH")
    print(f"Transaction Signature: {tx.signature[:30]}...")

    print("\n--- Verifying Transaction Signature ---")
    valid = tx.is_valid()
    print(f"Signature Verification Result: {valid}")
